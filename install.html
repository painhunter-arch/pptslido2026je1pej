投票システム　PowerPoint アドインのダウンロード（スライド作成者・編集者用）

確認しています…

ログイン

スライドを作る方（メイン編集者・共同編集者）用のページです。初めての方は新規登録してください。登録後すぐにダウンロードできます。

はじめての方

お使いのパソコンを選んでください

アドインを入れると、PowerPoint の中から会場アンケートを作り込み、スライドショー中に結果をそのまま映せます。アドインは毎回この投票システム（同じ公開サイト）から最新版を読み込むので、入れ直しは不要です。

Windows お使いのPC

PowerPoint（Microsoft 365／2019 以降）

  1. PowerPoint をすべて閉じる。
  2. ダウンロードした install-vote-addin.cmd をダブルクリックする。
    「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」。管理者権限は不要です（自分のユーザーにだけ登録します）。
  3. 「完了しました」と表示されたら閉じる。
  4. PowerPoint を開き、「挿入」→「アドイン」→「個人用アドイン」→ 上部の「開発者アドイン」（または「共有フォルダー」）にある「投票結果（自前）」を選んで「追加」。
うまく表示されないとき（共有フォルダー方式）
  1. 「設定ファイルだけ保存」で vote-addin.xml を保存する。
  2. PC内にフォルダ（例 C:\AddinCatalog）を作り、右クリック →「プロパティ」→「共有」で共有。表示されたパス（例 \\PC名\AddinCatalog）を控え、ファイルを入れる。
  3. PowerPoint →「ファイル」→「オプション」→「トラスト センター」→「トラスト センターの設定」→「信頼できるアドイン カタログ」に控えたパスを追加し、「メニューに表示する」にチェック → PowerPoint を再起動。
  4. 「個人用アドイン」→「共有フォルダー」から追加。

Mac お使いのMac

PowerPoint for Mac（Microsoft 365／2019 以降）

  1. PowerPoint を終了する。
  2. 「アプリケーション」→「ユーティリティ」→「ターミナル」を開き、下の1行をコピーして貼り付け、return キーを押す（ダウンロードした vote-addin.xml を所定の場所にコピーします）。
  3. PowerPoint を開き、「挿入」→「アドイン」→「個人用アドイン」から「投票結果（自前）」を選ぶ。
ターミナルを使わない方法
  1. Finder で「移動」→「フォルダへ移動…」（⇧⌘G）を開き、次を貼り付けて移動。
    ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  2. wef フォルダがなければ作り、その中に vote-addin.xml を入れる。

次にすること

  1. 新しく作る場合：管理画面の「プロジェクトを作成」で作り、メイン編集者になる。共同編集者に伝えるパスワードもここで決める。
  2. 共同編集する場合：メイン編集者から受け取ったプロジェクト番号とパスワードで参加する（アドインの中、または管理画面の「番号とパスワードで参加」）。
  3. スライドにアドインを挿入し、スライド作成者のための説明書に沿って質問を作る。

アドインと管理画面は、同じアカウント・同じプロジェクトにつながっています。どちらで作った質問も、もう一方から見えます。
